# Proma v0.19.83 更新

## 修复

- **模型图标**：未收录的 GPT 型号（如 `gpt-6.1-sol`、`gpt-6.1-terra`、`gpt-6-luna`）统一使用 OpenAI 品牌图标，不再因为同名模型同时存在于 Anthropic 渠道而误显示 Claude 图标。
- **思考深度顺序**：Agent 滑块和聊天页的思考等级固定按「关闭 → 低 → 中 → 高 → 极高 → 最大」展示，不再受渠道设置里的勾选顺序影响；只启用部分档位时也保持正确顺序。
- **上下文窗口**：优先使用运行时实际上报的窗口大小，用户手动调低的窗口不会再被按模型名推断的值抬高。
- **文件引用**：
  - 正确解析 Windows shell 盘符路径（Git Bash、WSL、Cygwin 别名）。
  - 文件或授权变化后重新解析，悬浮与点击检查始终反映最新状态。
  - 文件变化通知按会话范围筛选，减少无关的重复解析。
