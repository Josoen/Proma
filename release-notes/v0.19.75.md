# Proma v0.19.75 更新

## 新功能

- **接入 models.dev 模型目录** — 模型添加页面改为可搜索的模型目录，按「已启用 / 可用」分区展示；模型的上下文长度、最大输出、推理能力、默认思考等级等信息默认取自 models.dev。支持手动输入模型 ID，并可展开高级配置覆盖上下文长度、最大输出和思考等级。目录随安装包内置缓存，离线可用，不会向 models.dev 发送 API Key。
- **Agent 会话标题独立模型** — 「设置 → 模型配置」可单独指定生成会话标题的渠道和模型，不影响会话主模型。标题请求固定关闭思考等级；调用失败或返回空文本时自动生成本地标题，不再一直停留在「新 Agent 会话」。
- **重新生成会话标题** — 侧栏会话右键菜单新增「重新生成标题」，可随时按当前标题模型重新生成。
- **会话文件变更折叠** — 会话中的文件变更面板支持折叠较早的改动，减少长会话中的滚动噪音。

## 修复

- 允许删除默认的 DeepSeek 渠道。
- 清理已下线 provider 类型的残留引用，避免渠道配置报错。
- 修复模型目录接入后，模型选择和思考等级设置未正确恢复的问题。
